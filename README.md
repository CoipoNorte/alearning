# 🧠 [alearning](https://coiponorte.github.io/alearning/)

Guía interactiva estilo iOS para aprender Algoritmos, Machine Learning y Deep Learning. Animaciones con Framer Motion, sidebar colapsable y código copiable.

## 🔗 Temas cubiertos

**Algoritmos:** Intro · Big O · Búsqueda · Ordenamiento · Recursividad · Estructuras · Prog. Dinámica · Tips

**Machine Learning:** Intro · Tipos · Regresión · Clasificación · Clustering · Herramientas

**Deep Learning:** Intro · Redes Neuronales · CNN · RNN · Transformers/LLMs · Práctica Python

## 🛠️ Tecnologías

- **React 18** — Biblioteca de UI
- **Tailwind CSS v4** — Estilos utility-first
- **Framer Motion** — Animaciones iOS-like
- **Vite** — Build tool
- **Lucide React** — Iconos
